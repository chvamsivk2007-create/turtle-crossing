# Turtle Crossing 🐢🚗

A Frogger‑style game built with Python’s `turtle` graphics module.

---

## 📖 Description
- Player controls a turtle trying to cross the road
- Cars move horizontally across the screen
- Each successful crossing increases the level and speed
- Collision detection ends the game

---

## 📂 Features
- Object‑oriented design with multiple classes
- Dynamic car spawning and speed increase
- Scoreboard with level tracking
- Collision detection for game over
